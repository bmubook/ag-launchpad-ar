# 📱 مخطط تطبيق الجوال — React Native (Expo) + Supabase

## 1. متى تختار هذا المخطط / متى لا تختاره

| ✅ اختره عندما | ❌ لا تختره عندما |
|:---|:---|
| تطبيق جوال لـ Android و iOS وتفضّل JavaScript/TypeScript | تحتاج رسومات وحركات معقدة جداً بأداء أقصى — Flutter أنسب (`flutter.md`) |

## 3. سياسة الإصدارات
- المتطلب الأدنى: Node.js بالإصدار الذي يشترطه توثيق Expo الحالي، وتطبيق Expo Go على جوالك للتجربة.
- ثبّت الحزم بالأمر `npx expo install <الحزمة>` ليختار الإصدار المتوافق مع نسخة Expo — لا تستخدم أرقاماً من الذاكرة (البند 19).
- أنشئ المشروع بالأمر الرسمي الحالي من توثيق Expo.

## 4. هيكل المجلدات

```
app/                        ← الشاشات والمسارات (Expo Router)
├── (auth)/                 ← الدخول والتسجيل
├── (tabs)/                 ← الشاشات الرئيسية بعد الدخول
└── _layout.tsx             ← التهيئة: السمة، اللغة، حماية المسارات
src/
├── components/             ← مكونات ذرية قابلة لإعادة الاستخدام
├── lib/supabase.ts         ← عميل Supabase (حسب الدليل الرسمي)
├── services/               ← كل استدعاءات البيانات هنا
├── theme/tokens.ts         ← متغيرات التصميم (البند 32)
└── locales/ar.json, en.json
supabase/migrations/        ← الهجرات فقط (البند 18)
```
الأسقف: منطق ≤ 250 سطراً، شاشات ومكونات (TSX) ≤ 400 (البند 14).

## 5. خط الأساس الأمني
- **التطبيق عام بطبيعته:** المتغيرات التي تبدأ بـ `EXPO_PUBLIC_` تُضمَّن داخل التطبيق ويمكن قراءتها. ضع فيها رابط Supabase والمفتاح العام (publishable/anon) فقط، واعتمد على **RLS** للحماية. مفتاح `service_role` لا يدخل التطبيق أبداً.
- **RLS مغلق افتراضياً** مع سياسات المالك (المثال في `web.md` القسم 5).
- القيم الحساسة الإضافية في `expo-secure-store` لا في AsyncStorage.
- العمليات الحساسة (دفع، صلاحيات إدارية) تُنفَّذ على الخادم (Supabase Edge Functions) لا داخل التطبيق.

## 6. خط أساس الجودة (ما ينفّذه `/quality-setup`)
| الأداة | الاختيار |
|:---|:---|
| المدقق | ESLint بإعداد Expo الرسمي (`npx expo lint`) |
| المنسّق | Prettier |
| الاختبارات | Jest بإعداد `jest-expo` + React Native Testing Library — اختبار عرض لشاشة رئيسية واختبار لمنطق حقيقي |
| فحص الأنواع | `tsc --noEmit` ضمن أمر `check` |
| CI | `.github/workflows/ci.yml`: `npm ci` ← lint ← فحص الأنواع ← test |
| الاعتماديات | `.github/dependabot.yml` لـ npm و github-actions |

## 7. النشر
1. أنشئ حساب Expo واستخدم **EAS Build** لبناء نسخ Android و iOS في السحابة (لا تحتاج Mac لبناء iOS).
2. انشر عبر **EAS Submit** إلى Google Play و App Store (حسابا مطوّر مطلوبان).
3. أضف متغيرات البيئة في إعدادات EAS لا في الكود.
