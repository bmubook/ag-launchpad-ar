# 🗺️ المخططات التقنية الجاهزة (Blueprints)

أصعب قرار على المبتدئ هو **اختيار التقنيات في البداية**. القرار الخاطئ هنا يكلّف أسابيع لاحقاً. هذه المخططات حزم تقنية مجرّبة ومستقرة ومدعومة بمجتمعات كبيرة، مجهّزة مسبقاً بخط أساس للأمان والجودة، لتبدأ مشروعك على أساس قوي.

## أي مخطط يناسبك؟

| نوع مشروعك | المخطط | لماذا هذا الاختيار |
|:---|:---|:---|
| 🌐 موقع أو تطبيق ويب متجاوب | [`web.md`](web.md) | Next.js + Supabase: واجهة وخادم في مشروع واحد، ومصادقة وقاعدة بيانات جاهزتان |
| 📱 تطبيق جوال بـ Flutter | [`flutter.md`](flutter.md) | Flutter + Supabase: كود واحد لـ Android و iOS بأداء عالٍ |
| 📱 تطبيق جوال بـ React Native | [`react-native.md`](react-native.md) | Expo + Supabase: أسهل بداية للجوال لمن يعرف JavaScript أو سيتعلمها |
| ⚙️ خادم وقاعدة بيانات فقط | [`backend.md`](backend.md) | Supabase أولاً، أو Node.js + Hono عند الحاجة لـ API مخصص |

> 💡 **لماذا Supabase في كل المخططات؟** قاعدة بيانات PostgreSQL حقيقية مع مصادقة وتخزين ملفات وسياسات أمان الصفوف (RLS) جاهزة، وبيئة محلية للتجربة، وخطة مجانية مناسبة للبداية. توحيد الخلفية يعني أن ما تتعلمه في مشروع يفيدك في كل مشروع.

## كيف تُستخدم المخططات؟

| البيئة | الطريقة |
|:---|:---|
| **Claude Code** | في نهاية العصف الذهني (`/grill-me`) يعرض الوكيل المخطط المطابق كتوصية افتراضية عبر `/blueprint`، وبعد اعتماده يجهّز `/quality-setup` أدوات الجودة من القسم 6 في المخطط. |
| **Antigravity** | يقرأ الوكيل المخطط المطابق أثناء العصف الذهني ويقترحه كحزمة افتراضية (تعليمات `.agents/AGENTS.md`). |

## بنية كل مخطط (9 أقسام ثابتة)

1. متى تختار هذا المخطط / متى لا تختاره
2. الحزمة التقنية (مع روابط التوثيق الرسمي)
3. سياسة الإصدارات
4. هيكل المجلدات
5. خط الأساس الأمني
6. خط أساس الجودة — ما ينفّذه `/quality-setup`
7. النشر
8. أخطاء المبتدئين الشائعة وكيف يمنعها المخطط
9. المراحل المقترحة — أساس خطة المراحل في `project_map.md`

## ⚠️ سياسة الإصدارات (مهمة جداً)

التقنيات تتغير بسرعة. **لا تعتمد على أي رقم إصدار أو أمر مكتوب هنا دون تحقق**. قبل أي تثبيت يلتزم الوكيل بما يلي:

- **البند 4 — `rules_workflow.md`:** مراجعة التوثيق الرسمي الحالي.
- **البند 10:** مطابقة الإصدارات المثبتة على جهازك كما سجّلها الفحص البيئي.

المخططات تحدد **ماذا** نستخدم و**لماذا**، والتوثيق الرسمي يحدد **كيف** بالتفاصيل الحالية.

## الانحراف عن المخطط

المخطط توصية افتراضية لا قيد. إذا احتاج مشروعك تقنية مختلفة (مثلاً: Firebase بدل Supabase)، فهذا مسموح بشرطين:

- سبب واضح يُسجَّل كقرار في `decisions_log.md`.
- الحفاظ على خط الأساس الأمني وخط أساس الجودة نفسيهما.
